# 动画制作与交付清单

本文件规定制作范围和验收方式。参考身份为 `XH_REF_V1_PHOTO`；历史图集不作为外形依据。

## 必须完成的动作

| 目录名称 | 状态 | 必须可见的动作 |
| --- | --- | --- |
| `idle` | 待机 | 轻微呼吸、自然眨眼、回到中性姿态 |
| `running-right` | 右向奔跑 | 正确向右、四肢交替、可循环的步态 |
| `running-left` | 左向奔跑 | 独立生成的左向步态，耳朵身份正确 |
| `waving` | 挥爪 | 坐姿抬自身右前爪、招呼、放回 |
| `jumping` | 跳跃 | 蓄力、上升、最高点、下降、落地；上下高度保留 |
| `failed` | 失落 | 低头、轻微低落、恢复，不更换脸型 |
| `waiting` | 等待回应 | 期待地抬头、歪头、停顿、回正 |
| `running` | 工作思考 | 专注、轻点前爪；不是脚下奔跑 |
| `review` | 检查结果 | 小幅前倾、低头观察、眨眼、回正 |

## 中性图与16方向

交付一张中性默认图，以及 `look/000.png`、`022.5.png`、`045.png`、`067.5.png`、`090.png`、`112.5.png`、`135.png`、`157.5.png`、`180.png`、`202.5.png`、`225.png`、`247.5.png`、`270.png`、`292.5.png`、`315.png`、`337.5.png`。

方向是屏幕坐标：000上、090右、180下、270左，其他角度顺时针插值。中性直视不是000。使用真实的眼睛、头颈和自然耳毛跟随；不能把整只狗当指针旋转。下躯干和前爪作为固定锚点。

## 每个动作的文件

- `frames/000.png` 起的透明PNG帧序列。
- `preview.gif` 或可播放预览视频。
- `timing.json`：帧顺序、每帧时长、是否循环与循环范围。
- 该动作的提示词、起始关键帧、使用的身份参考。
- 可用时的项目源文件；不能提供时写清限制。

具体时长、帧数和导出分辨率按最终目标软件确认。不要把通用参考包当作已经通过某个软件导入验证的成品。

## 验收

逐动作检查开头、中间、结尾，快速运动与遮挡处增加检查。核对耳朵两侧、眼距、口鼻、色块、尾巴、头身比例、四肢数量、完整边界、固定机位下的尺度与脚底位置。循环要实际播放检查，不能只看一张接触表。

方向姿态要看完整顺序和两个半圈的接缝。正方向清晰；中间方向可以动作微妙，但不能落入相反象限或反向。任何失败都记录并修复，不能让错误帧继续主导后续生成。

最终提供 `QA.md`，逐项列明九组动作、16方向、循环、透明度和目标软件导出状态，诚实记录未完成部分。若要拼精灵图，先完成这些检查再拼接。
